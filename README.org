* Purpose

=run.py= is a small manifest-driven executor for reproducible analytical
packages.

The runner is designed around three manifest operations:

- =load_csv=
- =run_sql=
- =export_sql=

This version defines the manifest contract and authority zones. Execution
and validation behavior will be implemented in later commits.

* Command-line contract

Dry run:

#+begin_src shell
python3 run.py --dry-run path/to/manifest.csv
#+end_src

Dry run with verbose diagnostics:

#+begin_src shell
python3 run.py --dry-run --verbose path/to/manifest.csv
#+end_src

Execution:

#+begin_src shell
python3 run.py --run path/to/manifest.csv
#+end_src

The =--dry-run= and =--run= options are mutually exclusive.

* Manifest schema

The manifest has exactly five columns, in this order:

#+begin_example
step,mode,input,output,authority_zone
#+end_example

The final column is intentionally =authority_zone=. A later validation
commit will enforce this exact header structure.

* Manifest modes

Allowed modes are:

- =load_csv=
- =run_sql=
- =export_sql=

* Authority zones

Each manifest row must eventually declare exactly one authority zone from:

- =source=
- =prepared=
- =review=
- =focused=
- =inform=
- =business=
- =report=

These names are defined centrally in =manifest_schema.py= so later
validation and execution code can consume one canonical contract.
